# Árbol AVL Interactivo — Versiones Gráfica y Terminal

Aplicación interactiva desarrollada para implementar y comprender el funcionamiento de un Árbol AVL en Python en dos versiones: gráfica y de terminal. El programa permite insertar, eliminar y buscar nodos, además de visualizar el comportamiento del árbol y su balanceo automático mediante rotaciones.

## ¿Qué es este programa?

Este proyecto consiste en la implementación de un Árbol AVL interactivo en Python en dos versiones:

* Versión gráfica desarrollada con Tkinter
* Versión en terminal (consola)

Ambas permiten insertar, eliminar y buscar nodos, además de visualizar el comportamiento del árbol y su balanceo automático mediante rotaciones.

## Requisitos

* Python 3 instalado
* Tkinter (incluido por defecto en Python)

## ¿Cómo ejecutarlo?

### Versión gráfica (App)

1. Descargar el archivo app.py (o archivo principal de la interfaz)
2. Abrir la terminal en la carpeta del proyecto
3. Ejecutar: python app.py

### Versión terminal

1. Descargar el archivo main.py (o archivo principal)
2. Abrir la terminal en la carpeta donde se encuentra
3. Ejecutar: python main.py

## Funciones disponibles

### Versión gráfica

* Insertar nodos con animación
* Eliminar nodos
* Buscar nodos mostrando el recorrido
* Visualizar el árbol gráficamente
* Cargar secuencia personalizada #15
* Ver estadísticas en tiempo real
* Consultar log de operaciones

### Versión terminal

1. Insertar nodo
2. Eliminar nodo
3. Buscar nodo (muestra el recorrido desde la raíz)
4. Mostrar árbol en consola
5. Cargar secuencia personalizada #15
6. Generar árbol aleatorio
7. Ver estadísticas del árbol
8. Ver registro (log) de operaciones
9. Reiniciar árbol
10. Salir

## Interfaz (Versión gráfica)

La aplicación está dividida en tres secciones:

* Panel izquierdo: controles (insertar, eliminar, buscar)
* Panel central: visualización del árbol
* Panel derecho: estadísticas y registro de operaciones
